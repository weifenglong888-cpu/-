使用说明

登记调整。点「快速录入」，填写计划和时间，记录出价、人群、预算等改动的前后值。

补录效果。在右侧详情点「补录效果」，手动填写淘宝推广后台的同口径数据。填入任一调整后指标后，记录会从「待复盘」移到已补效果。

刷单登记。在侧栏进入后点「登记订单」，填写订单号、日期、店铺和金额。列表中可分别勾选确认收货、确认评价，点击「编辑」可修改或取消确认。按店铺、日期、状态筛选后可导出 CSV，导出的纯数字订单号会加文字前缀以保留位数。

日历与每日工作计划。在日历里选择日期，点击「添加计划」填写工作内容、时间、优先级和备注。每日工作计划页面可切换日期、勾选完成、编辑和删除计划，两个页面使用同一份安排。「导出当天」保存所选日期的 CSV，全部 JSON 备份会包含所有日期的计划。

保存数据。工作台可以离线打开，数据保存在当前浏览器。请使用同一浏览器和文件位置，更换电脑或清理缓存前先导出 JSON 备份。
